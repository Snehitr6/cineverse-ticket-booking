# 🎬 CINEVERSE — Movie Ticket Booking Website

CINEVERSE is a modern, responsive movie ticket booking website built with React.js and Vite. Users can explore movies, view movie details and cast information, select theatres and showtimes, choose seats, and view their booking confirmation.

## ✨ Features

- **Home Page** — Featured movies and movie discovery.
- **Movie Listings** — Browse movies and explore available options.
- **Movie Details** — View descriptions, ratings, genres, and movie information.
- **Cast & Crew** — Display cast members and attempt to load actor images.
- **Trailer Modal** — Watch movie trailers when a valid YouTube video ID is available.
- **Theatre Selection** — Choose from available theatres in Bengaluru.
- **Date Selection** — Select a movie date.
- **Showtime Selection** — Choose a preferred showtime.
- **Seat Selection** — Select seats for your booking.
- **Booking Confirmation** — View booking information after completing the booking flow.
- **Login & Signup Pages** — Authentication interface.
- **Responsive Design** — Supports desktop, tablet, and mobile screens.
- **CINEVERSE Branding** — Dark cinematic theme with red accents.

## 🛠️ Tech Stack

- React.js
- Vite
- JavaScript (ES6+)
- Tailwind CSS
- React Router DOM
- Lucide React
- Wikipedia API for best-effort actor image lookup

## 🎟️ Booking Flow

1. Open the home page.
2. Browse the available movies.
3. Open a movie's details page.
4. Select a theatre, date, and showtime.
5. Continue to seat selection.
6. Select available seats.
7. Confirm the booking and view the confirmation page.
